# SeerrNG Classic

Personalized SeerrNG frontend project aimed at restoring the compact, classic Seerr 3.5.1 look while preserving SeerrNG's expanded media support (movies, series, anime, music and books).

## Status

This repository was created as a separate customization project. The classic-style interface theme already present in SeerrNG is the starting point; changes should be made in this repository only and must keep current SeerrNG routes, permissions, APIs and media features working.

## Planned work

- Audit the classic theme and current shared UI components.
- Refine navigation, home rows, media cards and detail pages to align more closely with Seerr 3.5.1.
- Preserve SeerrNG-specific experiences for books, music and anime.
- Run lint, type checks and builds where the environment allows.
- Document the result and deployment steps.

## Important

No changes are intended for the upstream `snapetech-org/seerrng` repository.
