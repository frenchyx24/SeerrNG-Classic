# SeerrNG Classic

Classic Seerr styling adapted to current SeerrNG routes, permissions, and media features.

## Releases

- **1.0.4:** Declares public interface-theme routes in OpenAPI.
- **1.0.5:** Corrects mobile poster sizing and carousel heading wrapping.
- **1.0.7:** Adds all-wrapper homepage carousel sizing, cache-busted theme URL, and OpenAPI support for its version query.
- **1.1.1:** Adds fluid spacing and typography, safe-area padding, 44px touch targets, responsive carousel scrolling, reduced visual effects, faster-feeling transitions, and reduced-motion support.

The 1.1.1 image is published as ghcr.io/frenchyx24/seerrng-classic:1.1.1. Its stylesheet URL is versioned in the generated page to bypass stale browser/CDN cache entries.

Customizations preserve SeerrNG routes, permissions, APIs, and media features; upstream SeerrNG is unchanged.
